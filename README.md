# ITS 空室ウォッチ v1.0

ITS健保の保養施設について、希望日の空室を監視する個人用Webアプリです。施設と日付を登録し、新たな空きが出たらメールで知らせます。実際の申込とITS側の認証は公式サイトで行います。

## 機能

- ITS公式の施設一覧を取得し、施設・宿泊日・泊数・人数・通知先を登録
- 条件ごとの停止、再開、削除、手動確認
- 公式カレンダーの空きあり・残りわずか・空きなしを判定
- サーバー側の定期確認は3分ごと。新たな空きあり・残りわずかを検出するとメール通知
- 画面を開いている間は保存済みの結果を約1分ごとに更新
- 公式申込画面へのリンク（施設以外の日付・泊数・人数は公式画面で選択）

## 構成

| 用途 | 技術 |
| --- | --- |
| 画面とAPI | Next.js / Vinext、React、TypeScript、Tailwind CSS |
| 保存 | Cloudflare D1、Drizzle ORM |
| 定期実行 | Cloudflare Workers Cron Trigger（`*/3 * * * *`） |
| 通知 | Resend または Brevo API |
| ログイン | ホスティング側の認証。監視条件はユーザーIDで分離 |

定期実行は `scheduler/` の設定例から `app/api/cron/check/route.ts` を呼び出します。画面の「今すぐ確認」はメールを送りません。通知は定期実行で新たな空きが見つかった場合に送信します。

## ローカルで動かす

Node.js 22.13以降と pnpm が必要です。Windowsなら PowerShell でこのリポジトリのフォルダーを開き、次の順番で実行してください。

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm db:local
pnpm dev
```

ブラウザーで `http://localhost:5173` を開き、ローカル用のログイン画面からサインインします。開発サーバーだけが使うテストユーザーで、保存先も手元の D1 です。`pnpm db:local` は最初の一回と、今後マイグレーションが増えたときに実行します。

画面操作、条件の保存・停止・削除、画面からの手動確認を試せます。手動確認はITS公式へ実際にアクセスするので、短時間の連打は避けてください。ローカル起動だけでは定期実行やメール送信は動きません。

コードの型とビルドは以下で確認できます。

```sh
pnpm typecheck
pnpm build
```

## 公開・運用する場合

このリポジトリには運用サイトのID、監視データ、個人のメールアドレス、APIキーを含めていません。`hosting.example.json` はローカルの D1 バインディング名だけを示します。運用には別途、D1、認証、Worker、通知サービスを設定してください。`CRON_SECRET`、送信サービスのAPIキー、Sitesのバイパストークンは公開せず、各サービスのSecretに登録します。

`scheduler/` は設定例で、実際の運用Workerのデプロイ設定と認証情報は非公開で管理しています。ローカルのモックログインは開発サーバー上のループバック接続に限って使われます。

このアプリはITS公式の空室表示を参照する補助ツールです。空室の確保や申込の自動化は行いません。
